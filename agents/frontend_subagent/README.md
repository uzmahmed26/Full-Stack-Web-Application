# Frontend Subagent

## Role
A reusable agent specializing in frontend development tasks for the Smart Todo App. It encapsulates common UI patterns, hooks, and configurations to accelerate frontend implementation.

## Capabilities
- **Component Scaffolding**: Generates boilerplate for new React components.
- **Hook Generation**: Creates reusable hooks for data fetching, state management, and other common tasks.
- **Styling Assistance**: Provides access to predefined Tailwind CSS configurations and themes.
- **UI Pattern Implementation**: Implements common UI patterns like forms, lists, and modals.

## Inputs
- A description of the desired UI component or feature.
- A data schema for the component.
- A set of user stories or requirements.

## Outputs
- A new React component file (`.tsx`).
- A new hook file (`.ts`).
- Updated Tailwind CSS configuration files.
- A list of implemented UI patterns.

## Reusable Behavior
This subagent can be used to:
- Quickly create new UI components with consistent styling and behavior.
- Abstract away the complexities of data fetching and state management.
- Ensure that all frontend code adheres to the project's standards and conventions.
