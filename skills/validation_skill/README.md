# Validation Skill

## Role
A reusable skill for validating input data against a set of rules.

## Capabilities
- **Schema Validation**: Validates data against a JSON Schema or other schema format.
- **Custom Validation Rules**: Allows for the definition of custom validation rules.
- **Error Reporting**: Provides detailed error messages for invalid data.
- **Data Sanitization**: Sanitizes data to prevent common security vulnerabilities.

## Inputs
- The data to validate.
- The schema or set of rules to validate against.

## Outputs
- The validated and sanitized data.
- A list of validation errors.

## Reusable Behavior
This skill can be used by any agent that needs to validate input data. It can be used to validate data from user input, API requests, or any other source.
